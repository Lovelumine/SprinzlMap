## 7. caveat

1. **准确率分母是 2,529，处理与覆盖率分母是 2,530。** 引用总体数字时必须同时说明。
2. **该 run 是第 3 次 campaign（`attempt=3`）并含 21 条技术重试**，不是单趟 one-pass
   结果；与 one-pass baseline 比较时必须说明重试策略不同。
3. **网关的 reasoning 开关不等价于关闭 thinking**：同一 JSON 输出下 `thinking=disabled`
   仍返回非空 `reasoning`；512 token 空回复的根因是 reasoning 占满输出预算，修复方式是
   提高 `max_tokens`。
4. **消融与流程对照尚未在这个 2,530 队列上重跑。** 论文结果二引用的 no-Agent 对照
   （89.17% → 97.67% 等）来自已不在 store 里的 `publication-v39-*` 运行，其
   `results/agent_ablation_2530_*.tsv` 也已缺失，需要用当前模型与当前金标准重新生成
   后才能继续引用。
5. **外部泛化与家族外验证尚未完成**：本页全部指标属于固定队列的回顾性证据。

## 8. 本页支持的结论范围

支持的表述：

> 在 2,530 条经去重、且不与运行时模板完全相同的三域成熟 tRNA 上，SprinzlMap 为全部
> 序列产出逐残基 Sprinzl 坐标；在 2,529 条可评分序列上，逐残基准确率 97.56%，整条
> 完全匹配率 78.09%，自动接受覆盖率 80.24%，碱基保持率 100%。

不支持的表述：

- 与其他编号方法（直接编号 CM、固定 Harness、模板/区域 DP）的性能对照结论；
- 相似性簇级配对置信区间；
- 同配置重复运行的稳定性结论；
- 语言模型调用次数与词元成本的一致性结论；
- 线粒体、Sec、病毒或复杂内含子来源的通用编号能力；
- 已完成外部泛化验证。

如需上述证据，必须重新运行对应实验并在本页登记新的 run。
