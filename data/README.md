# Runtime template data

`tRNAs_flat.tsv` is not stored in this code repository. It is included in the
versioned Zenodo data archive under `templates/tRNAs_flat.tsv`.

For a full local run, place it at:

```text
data/tRNAs_flat.tsv
```

The current alignment and template-retrieval code resolves this path relative
to the repository working directory.
